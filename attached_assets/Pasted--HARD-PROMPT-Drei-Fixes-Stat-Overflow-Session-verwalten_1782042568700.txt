## FIX 2+3 — LabsHost liest `?manage=1` (LabsHost.tsx)
`const [forceDesktopView, setForceDesktopView] = useState(false);` ersetzen durch:
```tsx
  const [forceDesktopView, setForceDesktopView] = useState(() => {
    if (typeof window === "undefined") return false;
    try {
      return new URLSearchParams(window.location.search).get("manage") === "1";
    } catch {
      return false;
    }
  });
```
Wirkung: Mit `?manage=1` wird die MobileCompanion-Zwischenstufe übersprungen → bei `open`/`reveal` landet man direkt im Cockpit, sonst direkt in der Verwaltungs-/Settings-Ansicht.
