## PLAN (erst nach GO ausführen)

### Server — `server/routes.ts`
Direkt NACH dem `app.post("/api/impression/converse", ...)`-Block einen neuen Endpoint:
- `app.post("/api/impression/voice", async (req, res) => {...})`
- Rate-Limit über die vorhandene Funktion, aber EIGENER Eimer-Key: `checkConverseRateLimit("voice:" + ((req.headers["x-participant-id"] as string) || req.ip || "unknown"))`. Bei `!allowed` → 429 mit `retryAfter`.
- Body `{ text }`: trimmen, Guard `length >= 1 && length <= 600`, sonst 400 `{message:"text required"}`.
- `const { textToSpeech } = await import("./replit_integrations/audio/client.js");`
- `const buf = await textToSpeech(text, "fable", "wav");`
- `res.setHeader("Content-Type", "audio/wav"); res.send(buf);`
- try/catch → 500 `{message:"voice unavailable"}`. KEINE Persistenz, KEINE DB.

### Client — `client/src/labs/components/rating/impressionApi.ts`
Neue Funktion:
```ts
export async function fetchCooperVoice(text: string): Promise<ArrayBuffer> {
  const res = await fetch("/api/impression/voice", {
    method: "POST",
    headers: { "Content-Type": "application/json", ...pidHeaders() },
    body: JSON.stringify({ text }),
  });
  if (!res.ok) throw new Error(`voice failed: ${res.status}`);
  return res.arrayBuffer();
}
```

### Client — NEU `client/src/labs/components/rating/useCooperVoice.ts`
Ein gekapselter Hook. Hält einen lazy `AudioContext` (erst bei erstem `speak` erzeugen — iOS-Geste-konform, der erste Turn folgt immer auf einen Antwort-Tap). Exponiert:
- `speak(text: string): Promise<void>` — bricht laufende Wiedergabe ab; `fetchCooperVoice` → `decodeAudioData` → `AudioBufferSourceNode` → `AnalyserNode` → `destination`; `source.start()`.
- `speaking: boolean` (State).
- `levelRef: React.MutableRefObject<number>` — während der Wiedergabe per `requestAnimationFrame` aus `analyser.getByteTimeDomainData` ein RMS-Wert 0..1 hineinschreiben (KEIN State, kein Re-Render-Sturm). **Dies ist die Schnittstelle für Stufe 2 (Schimmer) — schon jetzt anlegen, aber noch nicht visuell nutzen.**
- `stop(): void` — Source stoppen, rAF abbrechen, `levelRef.current = 0`, `speaking=false`.
- Fehler in `speak` schlucken (Stimme ist additiv; bei Ausfall bleibt der Text lesbar).
