## 1. Production-Read: JA

Bitte führe per database-Skill (environment: "production") aus:

```sql

       character_maximum_length
FROM information_schema.columns
WHERE table_name = '_data_guard_snapshots'
ORDER BY ordinal_position;
```

Zusätzlich:

```sql
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename = '_data_guard_snapshots';
```

Und zur Sicherheit, was wirklich in den 3 Items drin ist (nur Strukturkontrolle,
keine sensitive Datenexposition — table_counts ist nur Row-Count-Zahlen):

```sql
SELECT id, table_counts, pg_typeof(table_counts) AS counts_type
FROM _data_guard_snapshots
ORDER BY id DESC
LIMIT 3;
```
