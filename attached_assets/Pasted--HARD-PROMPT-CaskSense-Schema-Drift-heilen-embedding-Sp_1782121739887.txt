# HARD PROMPT — CaskSense: Schema-Drift heilen (embedding-Spalten + Trigram-Indizes ins Schema)

## Ziel
Die `embedding`-Spalten und die fünf Trigram-Indizes existieren in der DB (via `server/search-init.ts`), stehen aber nicht im Drizzle-Schema. Dadurch will Replits Publish-Migration sie löschen (Datenverlust-Warnung). Wir deklarieren sie im Schema — exakt nach dem bereits existierenden Muster für `searchVector`/`tsvector` — damit der Migrations-Generator sie als gewollt erkennt und keine DROPs mehr vorschlägt. **Rein deklarativ: es wird nichts an der DB geändert, nur das Code-Schema an die Realität angeglichen.**

## WICHTIG — Verhaltensregeln
- **SCHRITT 0 zuerst (NUR LESEN):** Alle Anker bestätigen, kurze Bestätigung + Mini-Plan. **Dann WARTE auf mein OK.**
- Erst nach meinem OK ausführen.
- **KEIN commit. KEIN git. KEIN `drizzle-kit` / db-push / Migration.** Nur `shared/schema.ts` editieren.
- Vorbild ist der bereits vorhandene `tsvector`-customType und die `searchVectorIdx`-Index-Deklarationen — bitte genau dieses Muster spiegeln.

---

## SCHRITT 0 — Diagnose (nur lesen, dann warten)
In `shared/schema.ts` bestätige:
- Den `tsvector`-customType-Block (`const tsvector = customType…return "tsvector";`).
- In `whiskies`, `tastings`, `distilleries` je den Block `searchVector: tsvector("search_vector"),` + `}, (t) => ({` + die jeweilige `searchVectorIdx`-Zeile + `}));`.
- In `lexicon`: `searchVector` + `localeIdx` + `localeTermUnique` + `searchVectorIdx`.
- Die vier insert-Schemas (`insertTastingSchema`, `insertWhiskySchema`, `insertDistillerySchema`, `insertLexiconSchema`), die je auf `searchVector: true })` enden.
- Dass die Spalten-Properties `name`, `distillery` (whiskies), `title` (tastings), `name` (distilleries), `term` (lexicon) existieren.

**Wenn alles passt: kurze Bestätigung + Plan ausgeben und auf mein OK warten.**

## SCHRITT 6 — insert-Schemas: `embedding` mit-omitten (vier Stück)
Bei allen vier ist die Änderung dieselbe: `searchVector: true })` → `searchVector: true, embedding: true })`.
- `insertTastingSchema = createInsertSchema(tastings).omit({ id: true, createdAt: true, openedAt: true, closedAt: true, revealedAt: true, archivedAt: true, searchVector: true })` → am Ende `searchVector: true, embedding: true })`
- `insertWhiskySchema = createInsertSchema(whiskies).omit({ id: true, searchVector: true })` → `… searchVector: true, embedding: true })`
- `insertDistillerySchema = createInsertSchema(distilleries).omit({ id: true, searchVector: true })` → `… searchVector: true, embedding: true })`
- `insertLexiconSchema = createInsertSchema(lexicon).omit({ id: true, searchVector: true })` → `… searchVector: true, embedding: true })`

## VERIFIKATION
- `const vector = customType` erscheint **einmal**.
- `embedding: vector("embedding")` erscheint **viermal** (whiskies, tastings, distilleries, lexicon).
- `TrgmIdx: index(` erscheint **fünfmal** (whiskies ×2, tastings, distilleries, lexicon).
- Alle vier insert-Schemas enthalten `embedding: true` im `.omit({…})`.
- TypeScript bleibt sauber.
