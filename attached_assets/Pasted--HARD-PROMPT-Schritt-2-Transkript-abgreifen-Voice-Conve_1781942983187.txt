## 2. HOOK `useCooperVoice.ts` — Transkript sammeln
- `ConverseTurn`-Typ aus `./impressionApi` importieren (role: "taster" | "mentor"; text: string). Falls Import-Probleme: lokal kompatiblen Typ definieren.
- Neuer State: `const [transcript, setTranscript] = useState<ConverseTurn[]>([]);`
- In `connect()` direkt bei `setLedger(EMPTY_LEDGER)` auch `setTranscript([])` (Reset pro Session).
- In `dc.onmessage` zwei Fälle ergänzen (zusätzlich zu den bestehenden):
  - `if (msg?.type === "conversation.item.input_audio_transcription.completed" && msg?.transcript) { const t = String(msg.transcript).trim(); if (t) setTranscript(prev => [...prev, { role: "taster", text: t }]); }`
  - `if (msg?.type === "response.audio_transcript.done" && msg?.transcript) { const t = String(msg.transcript).trim(); if (t) setTranscript(prev => [...prev, { role: "mentor", text: t }]); }`
- Rückgabe-Objekt um `transcript` erweitern.
- HINWEIS (nicht fixen, nur kennen): Input-Transkripte können minimal verzögert eintreffen → Reihenfolge gelegentlich leicht unscharf. Für finalize/prose unkritisch, verfeinern wir später bei Bedarf.
