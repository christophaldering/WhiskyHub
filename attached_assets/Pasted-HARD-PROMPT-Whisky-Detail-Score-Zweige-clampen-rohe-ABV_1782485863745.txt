HARD PROMPT — Whisky-Detail: Score-Zweige clampen + rohe ABV defensiv rendern

KONTEXT: Im getWhisky-Detail-Endpoint (server/routes.ts) clampt nur der Tasting-Zweig. Die Zweige Collection/Journal/Historie schieben Roh-Scores ungeclampt in crossOverallScores/crossNoseScores/crossTasteScores/crossFinishScores → Detail zeigt >100. Außerdem wird für historische Einträge das ROHE Textfeld alcohol_raw direkt als abv zurückgegeben → unsinnige Werte wie "0.505 %". Wir wrappen die Score-Pushes in clampNormalized (bereits in der Datei importiert/genutzt) und parsen die Historie-ABV defensiv. EINE Datei, KEIN Schema, KEINE API-Form-Änderung.

STEP 4 — Historie-ABV defensiv parsen
Ersetze EXAKT:

durch:
          abv: (() => {
            const raw = String(histEntry.alcoholRaw ?? "").replace(",", ".");
            const m = raw.match(/[0-9]+(\.[0-9]+)?/);
            const v = m ? parseFloat(m[0]) : NaN;
            return Number.isFinite(v) && v >= 20 && v <= 96 ? v : null;
          })(),
