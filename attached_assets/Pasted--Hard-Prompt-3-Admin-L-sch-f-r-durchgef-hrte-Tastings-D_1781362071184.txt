## Schritt 1 — Edits

### Datei: `client/src/labs/pages/LabsTastingDetail.tsx`

**Edit 1 — Danger Zone für Admins (unten auf Detailseite)**

```typescript
{currentParticipant?.role === "admin" && (
  <div style={{ borderTop: "2px solid var(--labs-danger)", paddingTop: 20, marginTop: 20 }}>
    <h3 style={{ color: "var(--labs-danger)" }}>Danger Zone</h3>
    <button
      onClick={() => {
        const confirm = window.prompt(`Tasting "${tasting.name}" wirklich LÖSCHEN? Gib "${tasting.name}" ein zur Bestätigung:`);
        if (confirm === tasting.name) {
          tastingApi.delete(tastingId).then(() => navigate("/labs/tastings"));
        }
      }}
      style={{ background: "var(--labs-danger)", color: "white", padding: "10px 16px", borderRadius: 8, cursor: "pointer" }}
    >
      ⚠️ Tasting löschen
    </button>
  </div>
)}
```
