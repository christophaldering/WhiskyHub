# Hard Prompt: Sync-Validierung GitHub ↔ Replit

## Zweck
Ausschließlich Diagnose. **Keine Datei wird geändert, kein Befehl außer Lese-Operationen ausgeführt.** Ziel: Bestätigen, ob der GitHub-Stand (Commit `dc77f21c2fafca566d4cd967ef07436582949ec7` vom 29.04.2026, "Published your App") identisch mit dem aktuellen Replit-Arbeitsstand ist.

## ABSOLUTE SAFETY RULES
- ❌ KEINE Datei-Modifikationen (kein Edit, kein Create, kein Delete)
- ❌ KEINE Git-Operationen (kein commit, push, pull, checkout, reset)
- ❌ KEIN Server-Restart, kein Neubau, kein `npm install`
- ❌ Keine Änderungen an `server/`, `shared/schema.ts`, `.env`, `package.json`, `drizzle.config.ts`
- ✅ Nur `git log`, `git status`, `git diff --stat`, `cat`, `grep`, `find`, `ls`, `wc`
