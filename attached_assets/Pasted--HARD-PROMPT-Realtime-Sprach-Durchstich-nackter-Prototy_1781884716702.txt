## SERVER — `server/routes.ts`: Token-Endpoint
Neuer Endpoint `app.post("/api/voice-probe/token", …)`:
- `requireAuth` + Admin-Check; Nicht-Admin → 403.
- Erzeugt ein ephemerales Client-Secret über die Realtime-GA-API:
  `POST https://api.openai.com/v1/realtime/client_secrets` mit Header `Authorization: Bearer ${process.env.OPENAI_API_KEY}` und `Content-Type: application/json`. **KEIN** `OpenAI-Beta`-Header (das ist GA, nicht Beta).
  - Session-Config im Body: `session.type = "realtime"`, `model = "gpt-realtime-2"`, eine knappe Test-Instruktion (z.B. „Du bist ein Testpartner. Antworte kurz und freundlich auf Deutsch."), `reasoning.effort = "low"`.
  - **Die exakte Body-Struktur an der offiziellen Doku verifizieren:** `https://developers.openai.com/api/docs/guides/realtime-webrtc` und `.../client_secrets/methods/create`. Setze `expires_after` auf ~60 s.
  - Falls `gpt-realtime-2` einen „model not found" wirft, in der Diagnose melden — Fallback `gpt-realtime`.
- Antworte mit `{ value: <ephemeral key "ek_...">, expiresAt, model }`. KEINE Persistenz, keine DB.
- Eigener Rate-Limit-Eimer (z.B. `checkConverseRateLimit("voiceprobe:" + key)`).
- try/catch → 500 mit der echten Fehlermeldung im Body (für die Diagnose).

## CLIENT — `/labs/voice-probe` (admin-only)
Neue Seite mit einem Knopf „Verbinden" + großer Status-Zeile (`idle / fordere Token an / verbinde / verbunden / Fehler: <text>`). Styling über `LABS_THEME`/`FONT` (dunkel ok, es ist ein Test). Ablauf beim Klick:
1. `fetch("/api/voice-probe/token", { method:"POST", headers:{...pidHeaders()} })` → `EPHEMERAL_KEY`.
2. `const pc = new RTCPeerConnection();`
3. Remote-Audio: `<audio autoplay>` erzeugen, `pc.ontrack = e => audioEl.srcObject = e.streams[0]`.
4. Mikro: `const ms = await navigator.mediaDevices.getUserMedia({ audio:true }); pc.addTrack(ms.getTracks()[0]);`
5. `const dc = pc.createDataChannel("oai-events");` (Events nur in console loggen, mehr nicht).
6. `const offer = await pc.createOffer(); await pc.setLocalDescription(offer);`
7. SDP posten: `POST https://api.openai.com/v1/realtime/calls?model=gpt-realtime-2` mit `Authorization: Bearer ${EPHEMERAL_KEY}`, `Content-Type: application/sdp`, body = `offer.sdp`. Antwort (SDP) → `await pc.setRemoteDescription({ type:"answer", sdp:<antwort> })`.
8. `pc.onconnectionstatechange` → Status-Zeile aktualisieren; bei `"connected"` „verbunden — sprich jetzt".
- JEDER Fehler (Token, getUserMedia, SDP, ICE) landet SICHTBAR in der Status-Zeile UND in console.error. Nichts still wegfangen.
- Ein „Trennen"-Knopf, der `pc.close()` und die Mic-Tracks stoppt.
- Route admin-only registrieren (nicht in der normalen Navigation verlinken — direkter Aufruf genügt).
