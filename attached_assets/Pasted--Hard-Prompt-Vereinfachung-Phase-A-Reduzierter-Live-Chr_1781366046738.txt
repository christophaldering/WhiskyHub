# Hard Prompt: Vereinfachung Phase A — Reduzierter Live-Chrome ("Fokus-Modus")

**Datum:** 13.06.2026 · **Priorität:** NORMAL (UX) · **Basis:** origin/main `17466a8`
**Art:** 3 Edits über 2 Dateien (1× LabsLayout, 2× LabsLive). KEIN Schema, KEINE Migration, KEINE neue Datei.

---

## Worum es geht

Im Live-Modus (`/labs/live/:id`) sieht ein **eingeloggter Taster** heute die volle App-Chrome — Header mit Wortmarke/Glocke/Avatar **und die 4-Tab-Bottom-Nav** — zusätzlich zum internen "‹ Tasting"-Header. Ein **QR-Gast** dagegen sieht (über `cs_guest_shell`) bereits eine schlanke Shell. Zwei Taster am selben Tisch sehen also unterschiedlich viel Ablenkung.

Diese Änderung vereinheitlicht das: **Jeder Live-Taster** — eingeloggt wie Gast, in geführtem wie freiem Modus — bekommt den schlanken Fokus-Modus. Header und Bottom-Nav verschwinden; stattdessen oben ein **Grabber** (Sheet-Indikator) und die **CaskSense-Wortmarke** als ruhiger Anker. Der bestehende "‹ Tasting"-Ausgang und die Leave-Confirm-Logik (Dialog nur bei ungespeicherten Änderungen) **bleiben unverändert** — sie sind schon da.

**Bewusst NICHT in diesem Schritt:** echte Wisch-zum-Schließen-Geste (der Grabber ist vorerst nur sichtbarer Indikator; Schließen läuft über "‹ Tasting"). Host behält keine Sonderrolle — er kommt über den vorhandenen Cockpit-Button + "‹" zurück.

## Schritt 1 — Die 3 Edits (wörtlich, exakt)

### Edit 1 — `client/src/labs/LabsLayout.tsx`
Verallgemeinert die Gast-Branch auf alle Live-Taster und entfernt die dann ungenutzte `guestShell`-Variable.

**ALT:**
```tsx
  // Gast-Modus (WP 1): Gäste aus dem QR-Eingang sehen Lobby/Live ohne Header und Tabs.
  let guestShell = false;
  try { guestShell = sessionStorage.getItem("cs_guest_shell") === "1"; } catch {}
  if (guestShell && location.startsWith("/labs/live/")) {
    return (
      <div className={`labs-shell${theme === "light" ? " labs-light" : ""}`} lang={htmlLang}>
        {children}
      </div>
    );
  }
```

**NEU:**
```tsx
  // Live-Modus (Fokus): alle Taster -- eingeloggt wie QR-Gast -- sehen Lobby/Live ohne Header und Bottom-Nav.
  if (location.startsWith("/labs/live/")) {
    return (
      <div className={`labs-shell${theme === "light" ? " labs-light" : ""}`} lang={htmlLang}>
        {children}
      </div>
    );
  }
```
