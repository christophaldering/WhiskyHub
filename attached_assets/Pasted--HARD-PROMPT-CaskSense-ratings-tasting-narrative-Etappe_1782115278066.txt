# HARD PROMPT — CaskSense: ratings.tasting_narrative (Etappe 1a)

## Ziel
Die ratings-Tabelle bekommt ein additives Feld `tasting_narrative`, damit Coopers Verkostungsnotiz auch im Gruppen-Tasting gespeichert werden kann. Der Endpoint akzeptiert das Feld automatisch (`insertRatingSchema` wird via `createInsertSchema(ratings)` generiert; `upsertRating` reicht `data` durch) — daher **nur eine Schema-Zeile**, keine Server-Änderung.
