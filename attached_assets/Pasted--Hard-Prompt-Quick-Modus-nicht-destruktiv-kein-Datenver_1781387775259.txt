# Hard Prompt — Quick-Modus nicht-destruktiv (kein Datenverlust beim Re-Rating)

## Ziel
Im **Quick-Modus** (`QuickRating.tsx`) überschreibt das Speichern bisher die Detail-Scores (Nase/Gaumen/Abgang) mit dem Default-Wert und setzt Aromen + Detail-Notizen auf leer — Quick erfasst ja nur die Gesamtnote. Beim **Re-Rating** eines bereits detailliert bewerteten Drams gehen dadurch die vorhandenen Detail-Daten verloren.

**Entscheidung:** Quick wird **nicht-destruktiv**. Es aktualisiert nur die **Gesamtnote** und die **Gesamt-Notiz**; vorhandene Detail-Scores, Aromen und Detail-Notizen aus `initialData` bleiben unangetastet.

**Nur eine Datei:** `client/src/labs/components/rating/QuickRating.tsx`. Umsetzung über einen kleinen Helfer `buildQuickData`, der an allen drei Stellen (1× `onDone`, 2× `onChange`) das bisherige Inline-Objekt ersetzt.

> **Hinweis zu CompactRating:** bereits geprüft — **kein Handlungsbedarf**. Compact lädt Scores, Aromen und Notizen aus `initialData` und reicht sie durch; es ist schon nicht-destruktiv. Tisch wurde im vorigen Schritt gefixt. Damit sind nach diesem Prompt **alle vier Modi** (Quick/Eindruck/Kompakt/Geführt) datenerhaltend.

## Edit 1 — Helfer `buildQuickData` einfügen
**FIND:**
```tsx
  const [note, setNote] = useState(initialData?.notes?.overall ?? "");
```
**REPLACE:**
```tsx
  const [note, setNote] = useState(initialData?.notes?.overall ?? "");

  // Nicht-destruktiv: nur Gesamtnote + -notiz aktualisieren; vorhandene Detail-Scores, Aromen und Detail-Notizen aus initialData behalten.
  const buildQuickData = (overallScore: number, overallNote: string): RatingData => ({
    scores: {
      nose: initialData?.scores?.nose ?? defaultScore,
      palate: initialData?.scores?.palate ?? defaultScore,
      finish: initialData?.scores?.finish ?? defaultScore,
      overall: overallScore,
    },
    tags: initialData?.tags ?? { nose: [], palate: [], finish: [], overall: [] },
    notes: {
      nose: initialData?.notes?.nose ?? "",
      palate: initialData?.notes?.palate ?? "",
      finish: initialData?.notes?.finish ?? "",
      overall: overallNote,
    },
    overallExplicit: true,
  });
```

## Edit 2 — `onDone` umstellen
**FIND:**
```tsx
    onDone({
      scores: { nose: defaultScore, palate: defaultScore, finish: defaultScore, overall: score },
      tags: { nose: [], palate: [], finish: [], overall: [] },
      notes: { nose: "", palate: "", finish: "", overall: note },
      overallExplicit: true,
    });
```
**REPLACE:**
```tsx
    onDone(buildQuickData(score, note));
```

## Edit 3 — `onChange` am Score-Slider umstellen
**FIND:**
```tsx

```
**REPLACE:**
```tsx
            onChange?.(0, buildQuickData(v, note));
```

## Edit 4 — `onChange` am Notiz-Feld umstellen

```tsx
            onChange?.(0, buildQuickData(score, e.target.value));
```

## Smoke-Test (manuell) — Fokus Datenerhalt
1. Ein Dram detailliert bewerten (Eindruck oder Kompakt): Nase/Gaumen/Abgang + Aromen + Notiz. Speichern.
2. **Auf Quick wechseln** (Modus-Chip) und die **Gesamtnote ändern** → speichern.
3. Zurück auf Eindruck/Kompakt (oder Reload): **Detail-Scores, Aromen und Notizen sind unverändert** erhalten, nur die Gesamtnote ist neu.
4. Erst-Rating direkt im Quick-Modus (Dram ohne Vorbewertung) → funktioniert wie bisher (Detail-Scores auf Default, das ist korrekt).
