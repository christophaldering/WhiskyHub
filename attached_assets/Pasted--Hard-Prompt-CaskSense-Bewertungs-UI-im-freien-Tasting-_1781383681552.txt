# Hard Prompt — CaskSense: Bewertungs-UI im freien Tasting auf RatingFlowV2 (Eindruck-Default)

## Ziel
Im Live-Tasting gibt es zwei getrennte Bewertungs-Oberflächen in `client/src/labs/pages/LabsLive.tsx`:
- der **geführte Zweig** (`GuidedStepView`) nutzt bereits `RatingFlowV2` (mit Modus-Auswahl Quick/Eindruck/Kompakt/Geführt + Slider-Aufklapp),
- der **freie Zweig** (Haupt-Body, `canRate ? (…)`) nutzt eine **alte, fest verdrahtete Tab-Maske** (Nose/Taste/Finish/Overall + Slider + Aromen + Notizen) **ohne Modus-Konzept**.

Dieser Prompt ersetzt **nur die innere Tab-Maske des freien Zweigs** durch `RatingFlowV2` und startet dort standardmäßig im **Eindruck-Modus** (ohne vorgeschaltete Auswahl-Karten; Wechsel jederzeit über den Modus-Chip).

**Der ganze Live-Rahmen bleibt unverändert:** Reveal/Download/Pause-Banner, Dram-Karussell, Whisky-Karte (oben) sowie Handouts und Ranking (unten). Auch die Speicher-Maschinerie (`rateMutation` + `debouncedSave`) bleibt — sie wird nur neu angezapft. Die Sprachnotiz bleibt erhalten und ihr Transkript fließt weiter in die Notizen, exakt wie heute.

**Aufräumen folgt separat:** Der dann ungenutzte Alt-Maskencode (`activeDim`, `updateScore`, `updateNotes`, `InlineFlavorTags`-Nutzung, `studioOpen`, `computeAutoOverall` etc.) bleibt in DIESEM Schritt bewusst liegen — er bricht den Build nicht (kein `noUnusedLocals`) und wird in einem Folge-Prompt entfernt.

## Edit 3 — Innere Tab-Maske durch RatingFlowV2 + Sprachnotiz ersetzen

Im **freien Zweig** (Haupt-Body, **nicht** in `GuidedStepView`) steht der Block `{canRate ? ( <> … </> ) : ( … )}`.
Ersetze **alles von diesem Start-Marker bis inklusive diesem End-Marker** durch den neuen Block. Das umschließende `{canRate ? (`, `<>`, `</>`, `) : (` **bleibt** stehen — getauscht wird nur der Inhalt dazwischen.

**START-Marker** (erste zu löschende Zeilen — die Tab-Leiste-IIFE):
```tsx
              {(() => {
                const allDimsScored = DIMENSIONS.every((d) => scores[d] > 0);
```

**END-Marker** (letzte zu löschende Zeilen — das alte FlavourStudioSheet):
```tsx
              <FlavourStudioSheet
                open={studioOpen}
                onOpenChange={setStudioOpen}
                dimension={activeDim as DimKey}
                existingChips={activeChips}
                onChipsChange={handleStudioChipsChange}
              />
```

**ERSETZE den gesamten Bereich (START bis END, beide einschließlich) durch:**
```tsx
              <RatingFlowV2
                key={currentWhisky?.id}
                scale={mainScale}
                whisky={{ name: displayName, region: currentWhisky?.region || undefined, cask: currentWhisky?.caskType || undefined, blind: isBlind }}
                initialData={freeInitialData}
                preferredMode={freeRatingMode}
                showTisch={true}
                onChange={(draft) => {
                  if (draft.mode) setFreeRatingMode(draft.mode);
                  freeRatingDataRef.current = draft.data;
                  saveRatingData(draft.data, freeformMemo);
                }}
                onDone={(data) => { saveRatingData(data, freeformMemo); }}
                onBack={() => {}}
              />
              {VOICE_MEMOS_ENABLED && (
                <div className="mt-3">
                  <LabsVoiceMemoRecorder
                    participantId={currentParticipant?.id || ""}
                    memo={freeformMemo}
                    onMemoChange={(memoData) => {
                      setFreeformMemo(memoData);
                      saveRatingData(freeRatingDataRef.current, memoData);
                    }}
                  />
                </div>
              )}
```

Hinweis: Direkt vor dem START-Marker steht `<>`, direkt nach dem END-Marker steht `</>` gefolgt von `) : (`. Diese vier bleiben unverändert. Nach dem Edit muss die Struktur lauten: `{canRate ? ( <> <RatingFlowV2 …/> {VOICE_MEMOS_ENABLED && (…)} </> ) : ( …AuthGate… )}`.

## Smoke-Test (manuell, nach erfolgreichem Build)
1. Offenes (nicht-geführtes) Tasting als **frischer Gast** öffnen → die Bewertung startet **direkt im Eindruck-Modus**, ohne Auswahl-Karten.
2. Über den **Modus-Chip** auf Quick / Kompakt / Geführt wechseln → funktioniert; der gewählte Modus bleibt beim Dram-Wechsel erhalten.
3. Bewerten → wird **automatisch gespeichert** (kein „Speichern"-Knopf nötig).
4. **Aromen** wählen → bleiben nach Reload erhalten (landen im `[FLAVOURS]`-Teil der Notizen).
5. **Sprachnotiz** aufnehmen → Transkript fließt in die Notizen und wird gespeichert.
6. Tasting verlassen + erneut öffnen (Re-Rating) → vorhandene Werte + Aromen werden geladen.
