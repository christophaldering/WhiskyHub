# Hard Prompt: Phase 2 — Sprung-Adressen auf aktuelle Bibliothek-URLs umstellen

## Zweck
Alle aktiven Komponenten, die noch auf die alten `/labs/discover/*`-Routen springen, direkt auf die aktuellen `/labs/explore?tab=bibliothek&section=...&sub=...`-URLs umstellen. Damit entfällt der mehrstufige Redirect-Stack und der Back-Button funktioniert sauber.

Voraussetzung: Phase 1 (toter Code) ist abgeschlossen.

- ❌ Kein `git commit`, kein `git push` — nur Datei-Edits

- ❌ KEINE Änderungen an der Sub-Route `/labs/discover/research/grundlagen` etc. (das ist Phase 4)

## Änderung 1: `client/src/labs/components/LabsGlobalSearch.tsx`

Suchpattern: in den `route:`-Feldern der Pages-Registry (ca. Zeilen 86–93) und in den dynamischen Routen weiter unten (Zeilen 573, 593).

Statische Ersetzungen mit `str_replace` (alle 1:1):

```
"/labs/discover/lexicon"            → "/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=lexikon"
"/labs/discover/distilleries"       → "/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=destillerien"
"/labs/discover/bottlers"           → "/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=bottlers"
"/labs/discover/flavour-map"        → "/labs/explore?tab=whiskies&view=flavour-map"
"/labs/discover/guide"              → "/labs/explore?tab=bibliothek&section=tasting-wissen&sub=guide"
"/labs/discover/templates"          → "/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=lexikon"
"/labs/discover/rabbit-hole/themenspeicher" → "/labs/explore?tab=bibliothek&section=rabbit-hole&sub=themenspeicher"
"/labs/discover/research"           → "/labs/explore?tab=bibliothek&section=tasting-wissen&sub=research"
```

Für die zwei dynamischen Routen (Template-Literal):
```
`/labs/discover/distilleries?focus=${encodeURIComponent(String(h.title ?? ""))}`
→ `/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=destillerien&focus=${encodeURIComponent(String(h.title ?? ""))}`

`/labs/discover/lexicon?term=${encodeURIComponent(String(h.title ?? ""))}`
→ `/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=lexikon&term=${encodeURIComponent(String(h.title ?? ""))}`
```

## Änderung 2: `client/src/labs/pages/LabsLexicon.tsx` Zeile ~105

ALT:
```tsx
    navigate(`/labs/discover/lexicon${query}`, { replace: true });
```

NEU:
```tsx
    navigate(`/labs/explore?tab=bibliothek&section=nachschlagewerk&sub=lexikon${query.startsWith("?") ? "&" + query.slice(1) : query}`, { replace: true });
```

**WICHTIG:** Diese Änderung ist die einzige, die nicht 1:1 mappt — der bestehende `query`-String kann mit `?` beginnen, was kollidiert, wenn die neue URL bereits Query-Parameter hat. Die ternary-Ersetzung handhabt beide Fälle.
